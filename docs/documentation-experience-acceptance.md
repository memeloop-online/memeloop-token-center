# Documentation experience acceptance

This is an operator handoff for the published VitePress site. It is excluded from the public site. Record the deployed revision, site URL, browser/version, viewport, date, and outcome for each check; do not call a check passed from a source read alone. Use synthetic data and redact credentials, personal information, account identifiers and request bodies before retaining screenshots.

1. Open the site root with Chinese and English browser preferences in a fresh storage context. Confirm the matching home page, then explicitly switch languages and reload the root. Confirm the selected language persists. Repeat with storage disabled: navigation should remain usable. Check both the deployed base path and direct links to nested pages.
2. On desktop and a narrow viewport, switch light/dark appearance, navigate with keyboard, open and close the menu, search for a guide in each language, and follow previous/next and home links. Confirm readable contrast, visible focus, no clipped controls, and working links. Record any missing equivalent translation rather than assuming all pages have one.
3. Open each home-page product gallery card and its corresponding guide. Confirm the screenshot is legible, describes the linked workflow, and contains no sensitive data. Check both languages and themes; capture only sanitized evidence.
4. Follow the getting-started example without submitting it: confirm placeholders for address, credential and model are clear; identify where to obtain an authorized model and where to inspect requests. Model calls can incur charges, so execute one only under a separate authorized budget. Check any interactive examples for keyboard operation and understandable result/error states without entering real credentials.
5. Compare the Chinese and English navigation and guides, including managed model synchronization and the Codex account parameter section. Confirm default and strict modes, output-length limitations, and cost caveats remain understandable and equivalent. Report broken links or misleading instructions with the page, steps and sanitized screenshot.

The historical PR 522 published-guide receipt establishes the replacement text was published at that time; it does not establish the current browser experience, accessibility, screenshot safety, or completion of these checks. Keep failures and unverified items open for the responsible owner.
