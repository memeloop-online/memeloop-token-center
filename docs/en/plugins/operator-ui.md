# Operator UI extensions

An installed, signed plugin can contribute pages, cards, page extensions and model-route actions without rebuilding Token Center. Its self-contained ESM module exports `activateOperatorUi(host)`, uses the host's React and Fluent runtimes, and returns an `operator-ui-package-v1` component registry. Each manifest contribution identifies the component, module entry and SHA-256 digest; the installed snapshot serves the verified asset.

`operator.sidebar.tab` supports a custom category (`id` and `label`) and a plugin route. `operator.model-route.action` renders a `component_v1` component in each model-route row and supplies `props.context.modelRoute`. The action can use `props.api.navigate(destination, { modelRoute })` to pass the selected resource to a separate plugin page. Navigation uses the existing unsaved-change guard. Context stays in memory and expires when the user leaves the page or changes the tenant or credential.

The [Operator UI SDK](https://github.com/memeloop-online/memeloop-token-center/tree/master/web/operator-ui-sdk) exposes same-origin JSON requests through `api.requestApi({ path, method, body, signal })` and authenticated OpenAPI discovery through `api.discoverApi(signal)`. Requests use the current Operator credential and remain subject to backend scopes and resource authorization. The bridge supplies the current tenant for declared tenant inputs; it does not grant new permissions. A signed module runs in the Operator browser context, so install only trusted publishers.

Temporary model inference uses `POST /internal/v1/inference/chat/completions` for OpenAI chat or `POST /internal/v1/inference/messages` for Anthropic Messages, with `{ key_id, request }`. Choose an existing billing key the current service is authorized to use (`keys:write`); no plaintext key is returned to the plugin. The non-streaming request follows the selected key's model policy, routing, balance and accounting. Closing a plugin page does not guarantee cancellation of an upstream request or its cost. UI chat history can be temporary while normal request records remain subject to the deployment's retention policy.

Agent tools should expose only the operations needed for the task, keep credential-returning responses out of model context, show the consequences of mutations, and honor cancellation. Examples and the text playground live in the separate [example plugins repository](https://github.com/memeloop-online/memeloop-token-center-example-plugins).
