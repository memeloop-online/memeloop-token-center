# Memeloop Token Center

[简体中文](README.zh-CN.md)

Memeloop Token Center (MTC) is a team-oriented AI gateway for connecting clients to authorized model services through one endpoint.

The [English documentation](https://memeloop-online.github.io/memeloop-token-center/en/) covers client setup, supported protocols, routing concepts, usage, and plugins. For the complete Chinese overview, see [README.zh-CN.md](README.zh-CN.md).

## What MTC provides

- One endpoint for OpenAI-compatible, Anthropic-compatible, audio, and generation requests.
- Explicit model routes and client permissions, with a self-service view for each client credential.
- Request history, sessions, usage, and cost information in the same product surface.
- WebAssembly plugins for routing, provider integrations, and request policies.

Start with the [English documentation](https://memeloop-online.github.io/memeloop-token-center/en/) or read the [Chinese README](README.zh-CN.md).
